# Archive

This folder contains old, deprecated, experimental, or unused code kept only for reference purposes.

## Notes

- Code in this directory is **not actively maintained**
- Most files here are **unused** and may be outdated or broken
- Nothing in this folder should be considered production-ready
- Contents may be removed at any time

## Purpose

The archive exists mainly to:

- Preserve old implementations for historical reference
- Store abandoned experiments or prototypes
- Avoid permanently deleting potentially useful snippets
